# 🏗️ 토목기사 필기 CBT 120제 · 초등학생 쉬운 풀이 & AI 음성 듣기

- **라이브 웹앱 (Vercel)**: https://civil-cbt-120-easy.vercel.app/
- **수록 범위**: 2003~2026년 **61회차 · 7,320문제** (2023년 2·3회, 2024년 1회 기출 + 2026년 1회 모의고사 & 도면 125장 포함)

## 주요 기능
1. **🌱 초등학생 눈높이 쉬운 풀이 & 📖 원래 공식 풀이 탭 전환**
   - 82개 생활 비유 개념 카드 · 150여 개 용어 칩 · 2,280문항 단계별 계산 과정 제공
2. **🔊 저작권 무료 다정한 여성 AI 음성 (`Supertone Supertonic-2`)**
   - 라이선스: MIT (코드) / OpenRAIL-M (가중치) · 저작권 무료
   - 별도 백엔드 없이 브라우저 내장 ONNX(WebGPU/WASM)로 끊김 없이 연속 재생 (최초 1회 캐시 저장, 즉시 재생용 브라우저 기본 음성 전환 지원)
3. **⚡ 초고속 로딩 & 모바일 PWA 지원**
   - 회차·과목별 분할 JSON 지연 로딩(초기 로딩 ~85 KB), 연습 모드/실전 모드(180분), OMR, 오답노트, 북마크, 다크모드 지원
4. **🛡️ 다계층 보안 설계**
   - 엄격한 CSP · HSTS · SRI(SHA-384) · DOM XSS 화이트리스트 새니타이저 · Vercel WAF 적용 ([SECURITY.md](./SECURITY.md) 참고)

## 로컬 실행 방법 (선택)
```bash
python server.py
# http://localhost:8120/ 접속
```
*(Windows에서는 `앱_실행.bat`을 더블클릭하면 자동으로 실행됩니다.)*

## Vercel 배포
```bash
vercel --prod
```
